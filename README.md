# Tycoon Argentina — descargas

Simulador de negocios pixel art para Android. **11.0 "Sigma Deza":** conquistá la
Argentina región por región y provincia por provincia, cada una con su negocio y
su producto icónico (algodón en Santiago del Estero, Malbec en Mendoza, yerba en
Misiones, medialunas en CABA…).

## Cómo instalar

1. Entrá a **[Releases](../../releases/latest)** y bajá el archivo `.apk`.
2. Abrilo en el teléfono. Si Android lo pide, permití "instalar apps de origen
   desconocido" para el navegador o el administrador de archivos.
3. Si ya tenías una versión beta anterior, se instala encima.

Requiere Android 7.0 o superior. Es una versión **beta**: los anuncios son de prueba.

El código del juego no es público; este repositorio sólo publica las versiones.
